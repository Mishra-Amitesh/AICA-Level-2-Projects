Data safety

All data is saved inside this browser on this computer (not online). To protect it:

  • Click ⬇ Backup data (top right) weekly and keep the file on a USB / Google Drive / email.
  • To move to another computer, open this HTML file there and use ⬆ Restore backup.
  • Always open the file with the same browser (e.g. Chrome). Clearing browser data will erase records if there's no backup.
